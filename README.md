# 桂北·直营 季度经营看板

在线地址：https://leo322331.github.io/guibei-sales-board/ （用 Chrome / Edge 103 以上打开）

## 这套页面的特点

- **网页里直接传 Excel，当场出数**：不用装软件、不用跑脚本；传完数据存在你自己电脑的浏览器里，下次打开还是新数据。
- 版面、口径、图表与之前的单文件版一致；多两个页签：**【自助分析】**（自己拖维度交叉分析）、**【明细数据】**（搜索/导出原始出库明细）。

## 怎么更新数据

1. 从飞书多维表格导出这 5 张**原始 xlsx**（不要另存成 csv）：

   | 表 | 怎么认 |
   | --- | --- |
   | 客户出库单（上年同期） | 文件名含"2025财年" |
   | 客户出库单（本期） | 文件名含"2026财年" |
   | 区域总业绩达成-品牌 | 表头第一列是"战区" |
   | 直营区域总业绩 | 表头第一列是"区域" |
   | 销售经理总业绩-品牌 | 表头第一列是"销售经理" |

2. 打开页面 → 右上角 **【数据管理】** → 把表拖进虚线框（一次 5 张，或只拖这次变动的 1~2 张都行）。
3. 页面自动重算，右上角状态变成"已更新数据 · 更新于 …"。
4. 看一眼抽屉里的 **【核对结果】**：显示绿色"一致"才算对（明细汇总 与 区域表累计 差额≈0）；差额大说明导出区间对不上。

## 常见问题

| 情况 | 处理 |
| --- | --- |
| 提示"没识别出可用的表" | 确认导出的是原始 xlsx（不是 csv/xls），表头不要改 |
| 只想更新一张表 | 直接拖那一张，其它表沿用上次的 |
| 传错了想退回 | 【数据管理】→【清空本机缓存】 |
| 新增了月份（例如 9 月） | 直接传新表即可，月份和季度会自动扩展 |
| 换电脑 / 备份 | 用【导出数据包(.json)】，到新电脑再【导入数据包】 |

## 说明
